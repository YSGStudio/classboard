## Acceptance Criteria

- [ ] AC1 교사는 구글 로그인만, CSV로 아이디·4자리 비밀번호 발급·목록 내려받기, 중복 아이디 거부, 틀린·비활성·재발급 전 비밀번호 거부, 5회 실패 시 5분 잠금
- [ ] AC2 학생은 소속 교사의 모든 프로젝트를 보고, 다른 교사 프로젝트는 목록·API 0건
- [ ] AC3 하위 보드 10단계 생성·경로 표시, 순환 이동 거부, 순차형 미개방 보드 잠금
- [ ] AC4 기본 열 5개, 9번째 열 추가·마지막 열 삭제 거부
- [ ] AC5 다른 학생 카드 수정·이동·삭제 거부(화면·API), 교사는 허용
- [ ] AC6 360px에서 "다음 단계로" 버튼으로 이동
- [ ] AC7 다른 브라우저에 3초 안 반영
- [ ] AC8 가리기 방식별 학생 응답·실시간 이벤트에 숨겨진 데이터 없음
- [ ] AC9 모두 공개/다시 가리기가 3초 안 학생 화면에 반영
- [ ] AC10 부모 보드에서 30명 배당 시 하위 보드 30개 10초 안 생성, 본인 것만 접근, 부모는 계속 칸반으로 사용, 31번째 학생 자동 생성
- [ ] AC11 학생별 보기 카드 수·평가 상태가 DB와 일치
- [ ] AC12 카드 생성 1 + 이동 2 = 활동 기록 3행, 상세에 시간순 표시
- [ ] AC13 기준 재사용, 단계 1·6개 거부, 미리 보여주기 꺼지면 학생 읽기 불가, 하위 보드에 부모 기준 표시
- [ ] AC14 평가 화면은 학생의 하위 보드 또는 그 학생 카드만, 자동 저장 유지, (보드, 학생)당 평가 1행
- [ ] AC15 공개 전 0건, 공개 후 본인 것 1건만, 다른 학생 것 항상 0건
- [ ] AC16 평가 있는 기준 수정 거부, 복사해서 수정은 새 행
- [ ] AC17 360·768·1280px에서 주요 화면 가로 넘침 없음
- [ ] AC18 보드 권한: 없음·읽기·수정이 학생별로 적용(트리·API), 기본 권한 변경 반영, 회수 후 3초 안 사라짐
- [ ] AC19 이미지·PDF·링크 미리보기 표시, PDF 페이지 넘김, 내부망 링크 차단, 권한 없는 학생의 파일 접근 거부

## Human Checks

- [ ] 실제 태블릿·휴대폰에서 학생으로 카드 쓰기·옮기기·첨부가 편하다
- [ ] 가리기를 켠 수업 상황에서 다른 학생 카드가 안 보이고 "모두 공개" 때 한꺼번에 나타난다
- [ ] 보드 권한 설정에서 학생을 골라 권한을 주는 흐름이 헷갈리지 않는다
- [ ] 개인 하위 보드 배당 후 늘어난 트리를 탐색하기 어렵지 않다
- [ ] 학생 5명을 이어서 평가하는 흐름이 자연스럽다
- [ ] 학생 화면에서 공개된 평가가 알아보기 쉽다
- [ ] 교실 화면(TV·프로젝터)에서도 열 색·글자가 읽힌다
